# Todo List App with Express.js, MongoDB, and Pug

This is a simple Todo List web app built for Lecture 10 HW2 assignment.  
It uses Express.js for routing, MongoDB for data storage, and Pug as the template engine.

- [Express.js](https://expressjs.com/)
- [MongoDB + Mongoose](https://mongoosejs.com/)
- [Pug template engine](https://pugjs.org/)
- HTML/CSS (served via `public/`)

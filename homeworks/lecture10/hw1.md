Apply RESTful principles to the hw1 in lecture9
Create a new company	POST	/api/companies	
Create a new employee	POST	/api/employees	
Get a company by id	GET	/api/companies/:id	
Get an employee by id	GET	/api/employees/:id	
Update a company by id	PUT	/api/companies/:id	
Update an employee by id	PUT	/api/employees/:id
Delete a company by id	DELETE	/api/companies/:id
Delete an employee by id	DELETE	/api/employees/:id
Get all companies	GET	/api/companies
Get all employees	GET	/api/employees
Get employees of a company	GET	/api/companies/:id/employees
